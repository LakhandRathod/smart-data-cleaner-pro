
# Smart Data Cleaner Pro - Documentation

## 1. Project Overview
Smart Data Cleaner Pro is a Python desktop application that automates Excel and CSV data cleaning.

## 2. Technologies Used
- Python
- CustomTkinter
- Pandas
- OpenPyXL
- Tkinter

## 3. Main Features
- Excel and CSV file upload
- Remove duplicate rows
- Remove completely blank rows
- Remove leading and trailing spaces
- Convert text to Title Case
- Interactive data preview
- Before and after comparison
- Cleaning history
- Export cleaned files to Excel and CSV
- Dark and Light themes
- Optional drag-and-drop upload

## 4. Installation

```bash
python -m pip install -r requirements.txt
```

## 5. Run Application

```bash
python app/main.py
```

## 6. Output
The application exports cleaned data in Excel and CSV formats.
